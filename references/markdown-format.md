# Формат `report.md`

Файл – обычный Markdown с небольшим набором расширений. Кодировка UTF-8. Образец: `assets/example/report.md`.

## Front matter (метаданные)

```
---
title: Название работы
work: lr            # lr | dz | rgr | practice  (интервал 1,5; practice – 1,2)
author: Иванов И. И.
keywords: метод Ньютона, сходимость, Python     # нужны для реферата
sources: sources.json                           # по умолчанию sources.json рядом
section_new_page: false                         # true – каждый раздел 1-го уровня с новой страницы
auto_italic: true                               # латиница курсивом автоматически
---
```

## Титульный лист

**Необязателен.** Собирается автоматически, если в front matter есть `student` (или `teacher`); без них титульного листа не будет (`title_page: none` – явный отказ); образец – титульник ФИТ (шаблон ИДЗ, перенесён из проекта md-to-docx): колонтитул первой страницы (министерство, вуз, факультет, кафедра), вид работы, тема, дисциплина, вариант, блок «Студента / Курс / Группа / Направление / Проверил / Выполнил» с подчёркиванием и подписями, внизу – город и год.

```
discipline: Вычислительная математика      # обязательно
student: Иванов Иван Иванович              # обязательно (можно author:)
course: 3                                  # обязательно
group: Группа-001                          # обязательно
teacher: Петров Пётр Петрович              # обязательно
teacher_title: доцент, кандидат наук       # обязательно
program: 00.00.00 Название направления    # необязательно – строка «Направление»
work_number: 3                             # необязательно – «Лабораторная работа № 3»
variant: 7                                 # необязательно – строка «Вариант 7»
year: 2026                                 # по умолчанию – текущий год
```
Тема (`title:`) – обязательна, пишется в «ёлочках» автоматически (не добавляйте кавычки сами). Вид работы берётся из `work:` (lr → «Лабораторная работа», dz → «Домашнее задание», rgr → «Расчётно-графическая работа», practice → «Отчёт по практике»), его можно задать полем `work_type:`.

По умолчанию: университет – Омский государственный технический университет, факультет – ФИТ, кафедра – ПМиФИ, город – Омск. Другие значения: `university`, `faculty`, `department`, `city` (допустимы сокращения `ОмГТУ`, `ПМиФИ`); постоянные значения по умолчанию – `scripts/gostlib/titlepage.py` (`DEFAULTS`).

Не хватает обязательного поля – сборка остановится и перечислит недостающие; значения не угадываются. `title_page: none` – без титульного листа.

## Структурные элементы – заголовки `#` с точными названиями

`# Реферат`, `# Содержание` (текст под ним не нужен), `# Введение`, `# Заключение`, `# Список использованных источников` (текст под ним не нужен, список строится сам).

Любой другой `#` – **раздел** основной части (нумеруется автоматически: 1, 2, …), `##` – подраздел (1.1), `###` – пункт (1.1.1). Номера в заголовках **не пишите**.

Порядок в файле = порядок в документе. Обязательные элементы зависят от `work` (содержание – везде; реферат – только РГР и практика); необязательные включаются, только если они есть в файле.

## Приложения

```
# Приложение: Листинг программы {#app-code}
```
Пометки «(обязательное)» и «(справочное)» в документ не выводятся (старая запись `[обязательное]` в заголовке допустима, но игнорируется). Внутри приложения `##` – подразделы (А.1). Буквы А, Б, В… ставятся автоматически.

## Текст

| Что | Как |
|---|---|
| Абзац | строки до пустой строки склеиваются |
| **Жирный**, *курсив* | `**жирный**`, `*курсив*` |
| Код в строке | `` `max_iter` `` (DejaVu Sans) |
| Формула в строке | `$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$` |
| Разрыв строки | `<br>` |
| Разрыв страницы | `<!-- pagebreak -->` |
| Комментарий | `<!-- текст -->` (в документ не попадёт) |

Типографику вручную можно не соблюдать: `"кавычки"` → «кавычки», `—` и ` - ` → ` – `, латиница → курсив. Сообщения об автоисправлениях печатаются при сборке.

## Списки (плоские, без вложенности)

```
- пункт с тире «–»; порядок не важен;
- ещё пункт.

1) пункт с цифрой и скобкой (порядок важен);
2) следующий.

а) пункт с русской буквой и скобкой;
б) следующий.
```
Знаки препинания в конце пунктов расставляет автор (обычно `;` и в конце `.`).

## Ссылки и метки

Метка начинается с типа: `fig-`, `tab-`, `eq-`, `app-`, `sec-`.

| Объект | Метка | Ссылка в тексте |
|---|---|---|
| Рисунок | `{#fig-conv}` | `[[fig-conv]]` → «1» |
| Таблица | `{#tab-iters}` | `[[tab-iters]]` → «1» |
| Формула | `{#eq-newton}` | `[[eq-newton]]` → «2» (скобки ставьте сами: `формула ([[eq-newton]])`) |
| Приложение | `{#app-code}` | `[[app-code]]` → «А» |
| Раздел/подраздел | `{#sec-theory}` в конце заголовка | `[[sec-theory]]` → «1.2» |
| Источник | id из sources.json | `[@id]`, `[@id1; @id2]`, `[@id, с. 15]` → `[3]`, `[2, 3]`, `[3, с. 15]` |

Слово «рисунок», «таблица» пишите сами: `на рисунке [[fig-conv]] видно…`.

**Правило:** ссылка на рисунок/таблицу должна стоять в тексте **раньше**, чем сам рисунок/таблица; иначе сборка остановится с ошибкой.

## Рисунок

```
![Название рисунка без точки](img/график.png){#fig-conv width=13cm}
```
`width` – необязательно (`13cm`, `120mm`, `80%`); по умолчанию по размеру файла, но не шире текста и не выше 17 см. Подпись «Рисунок N – …» формируется автоматически. Пути – от папки с report.md.

## Таблица

```
Таблица: Название таблицы без точки {#tab-iters}

| Итерация | Приближение $x_n$ | Погрешность |
|:---:|:---:|---:|
| 1 | 3.0000 | 4.2e-01 |
| 2 | 1.8333 | 4.8e-02 |
```
Строка «Таблица: …» обязательна. Выравнивание столбцов – двоеточиями в строке `|---|` (`:---:` центр, `---:` вправо). В ячейках работают `$формулы$` и `**жирный**`. Символ `|` внутри ячейки – `\|`. Таблицы длиннее страницы разбиваются на «Продолжение таблицы N» автоматически (нужен Word).

## Формула в отдельной строке

```
$$ x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} $$ {#eq-newton}
```
или в несколько строк между `$$` и `$$ {#eq-…}`. Нумерация (1), (2), … справа – автоматическая. Метка необязательна, если ссылок на формулу нет.

Поддерживается подмножество LaTeX: `\frac`, `^`, `_`, `\sqrt[n]{}`, `\sum \prod \int \lim` с пределами, греческие буквы, `\leq \geq \neq \approx \to \Rightarrow \in \cup \cap \infty \partial`, `\left( … \right)`, `\overline \vec \hat`, `\text{…}`, `\mathbb{R}`, `pmatrix/bmatrix/cases/aligned`, `bmod`, `pmod{m}`. Неподдерживаемая команда даст понятную ошибку сборки.
