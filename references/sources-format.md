# Источники: `sources.json`

Список записей; генератор сам собирает библиографические описания по ГОСТ Р 7.0.100-2018, сортирует их по алфавиту (кириллица, затем латиница), нумерует и подставляет номера в `[@id]`. В список попадают **только процитированные** источники.

**Не выдумывай источники.** Используй те, что дал пользователь, что лежат в материалах задания или что ты реально нашёл и проверил (название, авторы, год, издательство). Нет уверенности в деталях – спроси пользователя или не включай. Дату обращения к сайту (`accessed`) ставь только если ресурс действительно открывался; иначе оставь пустой – в документе появится шаблон «дд.мм.гггг», который проверка пометит как ошибку.

## Общие поля

| Поле | Значение |
|---|---|
| `id` | короткий идентификатор для `[@id]` (латиница, цифры, `-`, `_`) |
| `type` | `book`, `article`, `chapter`, `web`, `standard`, `thesis`, `raw` |
| `authors` | список строк `"Иванов И. И."` (допустимо `"Иванов, И. И."` и `"Иванов Иван Иванович"`) |
| `title` | основное заглавие |
| `subtitle` | сведения, относящиеся к заглавию («учеб. пособие», «монография») |
| `url`, `accessed` | адрес и дата обращения `ДД.ММ.ГГГГ` |

## По типам

**book** – книга: `title`, `city`, `year` обязательны; `authors`, `subtitle`, `edition` («2-е изд., доп.»), `publisher`, `pages` (число), `isbn`, `responsibility` («под ред. И. И. Петрова»).
```json
{"id": "samarsky", "type": "book", "authors": ["Самарский А. А.", "Гулин А. В."], "title": "Численные методы",
 "subtitle": "учеб. пособие для вузов", "city": "Москва", "publisher": "Наука", "year": 1989, "pages": 432}
```
→ `Самарский, А. А. Численные методы : учеб. пособие для вузов / А. А. Самарский, А. В. Гулин. – Москва : Наука, 1989. – 432 с.`

**article** – статья из журнала: `title`, `journal`, `year` обязательны; `authors`, `volume`, `issue`, `pages` («27-48»), `doi`, `url`.
→ `Задорожный, В. Н. Расчет сетевых мотивов / В. Н. Задорожный, М. Н. Юдина // Вестник технологического университета. – 2019. – Т. 22, № 11. – С. 122–127.`

**chapter** – статья из сборника/конференции, глава книги: `title`, `container`, `year`; `authors`, `conference` («материалы III Всерос. конф. (Омск, 14–20 окт. 2018 г.)»), `editors`, `city`, `publisher`, `pages`.

**web** – сайт, страница, документация, репозиторий: `title`, `url` обязательны; `kind` («офиц. сайт»), `site` (название сайта для `//`), `city`, `year`, `authors`, `accessed`.
→ `NumPy documentation : офиц. сайт. – URL: https://numpy.org/doc/ (дата обращения: 02.11.2026).`

**standard** – стандарт: `number` («ГОСТ 7.32-2017»), `title`, `year`; `kind` («межгос. стандарт», «нац. стандарт Российской Федерации»), `approved` («утв. и введ. в действие Приказом … от … № …»), `city`, `publisher`, `pages`, `official` (по умолчанию `true` → «изд. офиц.»).

**thesis** – диссертация: `authors`, `title`, `degree` («дис. … канд. техн. наук»), `year`; `specialty`, `organization`, `city`, `pages`.

**raw** – готовая запись целиком, если тип не подходит: `{"id": "x", "type": "raw", "raw": "Полный текст записи."}` (сортируется по первому слову).

## Рекомендации ГОСТ при подборе

- Источники последних 3–5 лет желательны; не более 30% – за последние 10–20 лет (по совету правил).
- Ценнее: рецензируемые статьи, монографии, стандарты, отчёты НИР; учебники и сайты – не основа списка.
- Электронных ресурсов не более 1/3 (допустимо до 2/3).
- Нормативные акты и стандарты – по алфавиту вместе с остальными, если не выделены в отдельную группу.
